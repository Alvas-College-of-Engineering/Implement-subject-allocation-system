# Appointment Booking System

A simple Java-based appointment booking system that lets a user:
- View available doctors
- Book an appointment for a patient
- View scheduled appointments

## Files

- `AppointmentBookingSystem.java` — main program and all classes for the booking system
- `Patient.class`, `Doctor.class`, `Appointment.class`, `BookingSystem.class` — compiled bytecode files

## How to compile

Open a terminal in the project folder and run:

```powershell
javac AppointmentBookingSystem.java
```

## How to run

```powershell
java AppointmentBookingSystem
```

## Usage

The program presents a menu:
1. View Doctors
2. Book Appointment
3. View Scheduled Appointments
4. Exit

Enter the option number, then follow the prompts to book or view appointments.

## Notes

- The system includes three default doctors: Cardiology, Dermatology, and Orthopedics.
- Appointments are stored in memory only and reset when the program exits.
